# 4. Mensajería y notificaciones

## Mensajería interna (chat en tiempo real)

El menú **Mensajes** es el chat del equipo:

- Conversaciones **directas** entre dos usuarios.
- Indicador de **presencia** (quién está en línea y última conexión).
- Se puede crear una conversación desde una licitación (flujo colaborativo) para
  comentar una oportunidad específica sin salir de la plataforma.

## Centro de notificaciones (campanita)

La campanita de la barra superior agrupa todo lo que el sistema detecta solo:

| Tipo | Qué significa |
|------|---------------|
| Nueva licitación | Calza con una de tus alertas configuradas |
| Aclaración detectada | Una licitación que sigues (⭐) publicó una aclaración |
| Resultados del scraper | Corridas automáticas de descarga de documentos |
| Sincronización | Ciclos de actualización de licitaciones |

Acciones: marcar una como leída, marcar todas como leídas, eliminar notificaciones.

> Las notificaciones de scraper/sincronización (broadcast) solo las ven los
> administradores.
