# Manual de Usuario — Plataforma de Gestión de Mercado Público (MPM)

Guía paso a paso para usar la plataforma, escrita para personas sin conocimientos
técnicos. Si eres administrador del sistema, consulta además la sección
[Administración](06-administracion.md).

## Roles y qué puede hacer cada uno

| Rol | Qué puede hacer |
|-----|-----------------|
| **Usuario** | Toda la plataforma: licitaciones, análisis, alertas, competidores, mensajería |
| **Analista** | Lo mismo que Usuario (la diferenciación es organizacional) |
| **Administrador** | Todo lo anterior + crear usuarios y ver la actividad del sistema |
| **Super Admin** | Todo lo anterior + gestionar administradores y cambiar el motor de IA |

> Si no sabes qué rol tienes, entra a **Mi perfil** (ícono de tu cuenta arriba a la derecha).

## Primeros pasos

1. **Iniciar sesión**: entra a la URL de la plataforma, escribe tu correo y
   contraseña. Si no recuerdas tu contraseña, usa "¿Olvidaste tu contraseña?" —
   recibirás un correo para crear una nueva.
2. **Cambia tu contraseña inicial**: la primera vez, haz clic en tu nombre (arriba
   a la derecha) → **Cambiar contraseña**.
3. **Configura tus alertas personales** (opcional): en el menú de tu cuenta →
   **Configuración**, puedes agregar un correo o chat de Telegram para recibir
   alertas fuera de la plataforma.

## Conceptos clave

- **Licitación**: proceso público de compra publicado en Mercado Público que la
  plataforma sincroniza automáticamente.
- **Workspace de análisis**: expediente de una licitación adjudicada donde se
  cargan los documentos de evaluación (PDF) para analizarlos con IA.
- **Alerta**: regla que avisa cuando aparece una licitación que calza con tus
  criterios (palabra clave, montos, organismos).
- **Seguir una licitación** (ícono de estrella ⭐): te avisa cuando la licitación
  tiene aclaraciones nuevas.
