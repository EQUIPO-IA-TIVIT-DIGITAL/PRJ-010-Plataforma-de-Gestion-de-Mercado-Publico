# 1. Licitaciones: buscar, seguir y exportar

## El listado principal

Al entrar, el sistema muestra el **listado de licitaciones** sincronizadas desde
la API oficial de Mercado Público (se actualiza solo, todos los días).

Cada fila muestra: código, nombre, organismo, estado, tipo, fecha de publicación
y fecha de cierre.

## Buscar y filtrar

- **Búsqueda por palabra clave**: escribe un término y presiona Enter. Filtra por
  nombre, código u organismo.
- **Búsqueda inteligente** (IA): en la pestaña "Búsqueda inteligente" puedes
  escribir una frase en lenguaje natural, por ejemplo
  *"adquisición de software y equipamiento tecnológico"*. El sistema entiende la
  intención y trae licitaciones relevantes aunque no usen las mismas palabras.
- **Filtros**: por estado, tipo, organismo y rango de fechas.

## Ver el detalle de una licitación

Haz clic en cualquier licitación para abrir su ficha:

- Código, nombre y organismo
- Montos (estimado, adjudicado si existe)
- Fechas clave (publicación, cierre, adjudicación)
- Link directo al portal oficial de Mercado Público
- Estado actual

## Seguir una licitación ⭐

El ícono de estrella en cada fila **sigue** la licitación. El sistema la vigila
automáticamente y te avisa (centro de notificaciones) si aparecen
**aclaraciones nuevas** — información que el organismo publica después del cierre
y que puede cambiar las condiciones.

## Exportar a Excel

Usa el botón de exportación del listado para descargar las licitaciones visibles
en un archivo Excel, útil para compartir o analizar fuera de la plataforma.
