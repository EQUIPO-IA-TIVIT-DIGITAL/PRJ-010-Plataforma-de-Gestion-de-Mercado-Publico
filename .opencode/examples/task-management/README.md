# Task Management — Reference Example

This directory contains a complete, concrete example of all artifacts generated by the Framework Agéntico for a **Task Management** module. Use this as a reference when implementing new modules.

## Module: Task Management

A simple task management system with:

- **Tasks** — Assignable work items with status and priority
- **Users** — System users who create/own tasks
- **Comments** — Notes attached to tasks
